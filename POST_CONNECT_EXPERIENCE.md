# Ansible Automation Platform Connector — что видит и чем управляет пользователь после подключения

## 1. Целевой пользователь
DevOps/инфраструктурный инженер, использующий Ansible Automation Platform (AWX/Tower)
для управления конфигурацией серверов и оркестрации плейбуков.

## 2. Момент истины после подключения
Сразу после `connect_ansible` — сводка по недавним job-запускам: сколько успешно, сколько
упало, на каком хосте конкретно провалился плейбук.

## 3. Что пользователь видит
- Job templates (готовые к запуску плейбуки с параметрами) — `list_job_templates`.
- Историю запусков (jobs) со статусом и логами — `list_jobs`, `get_job_stdout`.
- Инвентари (список серверов, которыми управляет Ansible) — `list_inventories`,
  `list_hosts`.
- Проекты (git-репозитории с плейбуками) — `list_projects`.
- Учётные данные (credentials, без значений) — `list_credentials`.
- Расписания автозапуска — `list_schedules`.
- Уведомления (куда шлются алерты об успехе/провале) — `list_notification_templates`.

## 4. Чем пользователь может управлять
- Запускать job template с нужными переменными — `launch_job`.
- Отменять выполняющийся job, массово — `cancel_job`, `bulk_cancel_jobs` (destructive —
  необратимо прерывает выполнение плейбука на серверах).
- Синхронизировать проект с последней версией из git — `sync_project`.
- Обновлять инвентарь (добавить/убрать хост) — `create_host`, `remove_host`.
- Создавать/менять расписание — `create_schedule`.
- Утверждать job, ожидающий workflow-approval (ручной gate перед продакшн-деплоем) —
  `approve_workflow_node`.

## 5. "Вау"-момент для демо потенциальному клиенту
"Смотри — говорю Webbee: 'какой плейбук упал на каком сервере при последнем деплое?'.
Она находит через `get_job_stdout` точную ошибку на конкретном хосте — а я прошу
перезапустить после фикса, `launch_job` делает это сразу."

## 6. Что делает это "заточенным под него"
`list_inventories`/`list_hosts` работают с РЕАЛЬНОЙ инфраструктурой клиента (его серверы,
его группы хостов) — Webbee не абстрагируется, видит именно то, чем он управляет.
